# Form

<Ingress>
The `UseForm` [hook](../02_RulesOfHooks.md) provides comprehensive form handling with validation, submission, and state management for complex forms in your [application](../../../01_Onboarding/02_Concepts/15_Apps.md).
</Ingress>

## Overview

The `UseForm` [hook](../02_RulesOfHooks.md) enables form management:

- **Form Building** - Build forms using the form builder pattern
- **Validation** - Built-in validation support with validation views
- **Submission** - Handle form submission with async support
- **Loading States** - Track form loading and submission states
- **Type Safety** - Strongly typed form models
