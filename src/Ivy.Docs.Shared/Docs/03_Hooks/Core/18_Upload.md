# Upload

<Ingress>
The `UseUpload` [hook](../02_RulesOfHooks.md) provides file upload functionality, allowing users to upload files from their [application](../../../01_Onboarding/02_Concepts/15_Apps.md) with progress tracking and validation.
</Ingress>

## Overview

The `UseUpload` [hook](../02_RulesOfHooks.md) enables file upload capabilities:

- **File Upload** - Handle file uploads from users
- **Progress Tracking** - Monitor upload progress
- **Upload Handlers** - Custom upload processing logic
- **Validation** - Validate files before upload
- **Multiple Files** - Support for single or multiple file uploads
