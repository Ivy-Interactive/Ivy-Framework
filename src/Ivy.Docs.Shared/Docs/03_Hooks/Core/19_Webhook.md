# Webhook

<Ingress>
The `UseWebhook` [hook](../02_RulesOfHooks.md) creates HTTP endpoints that can be called from external systems, enabling integration with third-party services and webhooks.
</Ingress>

## Overview

The `UseWebhook` [hook](../02_RulesOfHooks.md) enables HTTP endpoint creation:

- **HTTP Endpoints** - Create HTTP endpoints for external access
- **Request Handling** - Process incoming HTTP requests
- **Response Control** - Return custom HTTP responses
- **Async Support** - Support for asynchronous request processing
- **Integration** - Enable integration with external services and webhooks
