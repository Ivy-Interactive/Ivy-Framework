# Refresh Token

<Ingress>
The `UseRefreshToken` [hook](../02_RulesOfHooks.md) provides a mechanism to manually trigger component refreshes, giving you control over when [components](../../../01_Onboarding/02_Concepts/02_Views.md) should re-render.
</Ingress>

## Overview

The `UseRefreshToken` [hook](../02_RulesOfHooks.md) enables manual component refresh control:

- **Manual Refresh** - Trigger component re-renders on demand
- **Refresh Control** - Get a token that can be used to force updates
- **Selective Updates** - Control when and how components update
