# Blades

<Ingress>
The `UseBlades` [hook](../02_RulesOfHooks.md) creates a blade (side panel) interface, providing a slide-out panel for additional content, navigation, or actions.
</Ingress>

## Overview

The `UseBlades` [hook](../02_RulesOfHooks.md) enables blade/side panel functionality:

- **Side Panels** - Create slide-out side panels
- **Root Blade** - Define the root blade content
- **Customizable** - Set title and width for blades
- **Navigation** - Navigate between different blades
- **Overlay** - Automatic overlay and backdrop support
