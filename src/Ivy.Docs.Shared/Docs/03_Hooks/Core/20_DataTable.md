# DataTable

<Ingress>
The `UseDataTable` [hook](../02_RulesOfHooks.md) provides a connection to queryable data sources, enabling efficient data table rendering with sorting, filtering, and pagination.
</Ingress>

## Overview

The `UseDataTable` [hook](../02_RulesOfHooks.md) enables data table functionality:

- **Queryable Data** - Connect to IQueryable data sources
- **Efficient Rendering** - Optimized rendering for large datasets
- **Sorting & Filtering** - Built-in support for data operations
- **Pagination** - Automatic pagination support
- **ID Selection** - Custom ID selector for row identification
