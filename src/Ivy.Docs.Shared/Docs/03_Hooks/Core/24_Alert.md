# Alert

<Ingress>
The `UseAlert` [hook](../02_RulesOfHooks.md) provides alert and notification functionality, enabling you to display messages, confirmations, and notifications to users in your [application](../../../01_Onboarding/02_Concepts/15_Apps.md).
</Ingress>

## Overview

The `UseAlert` [hook](../02_RulesOfHooks.md) enables alert and notification management:

- **Alert Display** - Show alerts and notifications to users
- **Alert View** - Render alert UI components
- **Show Delegate** - Programmatically trigger alerts
- **Notification Types** - Support for different alert types (info, warning, error, success)
